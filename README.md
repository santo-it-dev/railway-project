# railway-project

Scopo del progetto: Studio di dati reali relativi a malfunzionamenti in ambito railway salvati in un database di tipo non relazionale (MongoDB), l'implementazione e modellazione di un sistema per la gestione di tali dati in ambiente Python, l'adozione di pratiche allo scopo di garantire sicurezza e efficienza tramite l'utilizzo di plugin esterni (come bcrypt e JWT) e l'analisi delle performance del sistema mediante il framework di testing Locust.
